# Guess Game

A number guessing game developed with Python and Tkinter.

## Overview

Guess Game is a desktop application where players try to guess a randomly generated number.

The game includes multiple difficulty levels and a graphical interface built with Tkinter Canvas.

## Difficulty Levels

| Difficulty | Number Range | Attempts |
|---|---:|---:|
| Easy | 1–10 | 5 |
| Medium | 1–100 | 10 |
| Hard | 1–1000 | 20 |

## Features

- Three difficulty levels
- Random number generation per guess
- Guess validation
- Remaining attempts counter
- Score system
- Highest score tracking during the current session
- Play again option
- Custom Canvas buttons
- Graphical interface using Tkinter

## Technologies

- Python
- Tkinter
- Random module
- Object-Oriented Programming

## Requirements

- Python 3.10 or newer
- Tkinter

Tkinter is included with most standard Python installations.

## Installation

1. Download or clone this repository.
2. Open the project folder.
3. Open the `GUESS GAME` directory.
4. Run:

```bash
python main.py
```

## How to Play

1. Select a difficulty level.
2. Enter your guess.
3. Submit your guess.
4. If up to half of your remaings are true guesses you will be the winner else you will be the loser
5. Start another round using the Play Again option.
